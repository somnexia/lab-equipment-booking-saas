# Диаграмма вариантов использования (Use Case)

## Файл диаграммы

## Граница системы

**Lab Equipment Booking SaaS** — веб-сервис и REST API для учёта лабораторного оборудования и бронирования временных слотов.

## Акторы

| Актор | Роль в БД | Описание |
|-------|-----------|----------|
| Системный администратор | `system_admin` | Платформа, все организации |
| Администратор лаборатории | `lab_admin` | Одна организация, пользователи, брони |
| Менеджер оборудования | `equipment_manager` | Каталог и парк приборов |
| Исследователь | `researcher` | Бронирование, управление бронями в лаборатории |
| Студент | `student` | Свои брони, просмотр каталога |
| Техник | `technician` | Статусы ТО / неисправности |
| Внешняя система (LIMS) | — | Интеграция через REST API |

## Варианты использования

| ID | Вариант | Акторы |
|----|---------|--------|

| ID | Вариант | Акторы |
|----|---------|--------|

### Оборудование

## Соответствие реализации

| Вариант | Статус в приложении |
|---------|---------------------|
| UC-01, UC-02, UC-03 | Реализовано (`/api/auth`, страницы `/auth/login`, `/auth/register`) |
| UC-22 | Реализовано (`GET /api/equipment`) |
| UC-30–33 | Частично (`/api/bookings`; без проверки конфликтов и орг.) |
| UC-21, UC-20, UC-10–12 | Планируется (есть в CRUD-матрице) |
| UC-40 | REST API есть, полная LIMS-интеграция — в планах |
