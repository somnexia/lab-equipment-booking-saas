# Введение

## Название проекта

**Lab Equipment Booking SaaS** — облачный сервис бронирования лабораторного оборудования для учебных и научных организаций.

## Идея стартапа

В университетах и НИИ десятки приборов и установок используются разными группами, но учёт часто ведётся в таблицах или чатах. Это приводит к конфликтам расписания, простою дорогого оборудования и отсутствию прозрачной статистики загрузки.

Наш стартап предлагает **единую платформу**: каталог оборудования по лабораториям, онлайн-бронирование по временным слотам, роли для сотрудников и студентов, REST API для интеграции с **LIMS** (Laboratory Information Management System).

## Цели проекта

1. **Автоматизировать** резервирование лабораторного оборудования в рамках организации.
2. **Разграничить доступ** по ролям (от гостя до системного администратора).
3. **Хранить данные** в реляционной СУБД MySQL с целостностью связей (FK, статусы).
4. **Предоставить API** для внешних систем (мобильное приложение, LIMS, отчёты).
5. **Подготовить основу** для облачного развёртывания (SaaS-модель, мультитенантность по `organization_id`).

## Задачи

| № | Задача |
|---|--------|
| 1 | Спроектировать БД: организации, пользователи, категории, оборудование, бронирования |
| 2 | Реализовать CRUD и бизнес-правила (статусы оборудования и броней) |
| 3 | Внедрить аутентификацию (JWT) и авторизацию по ролям |
| 4 | Разработать веб-интерфейс и REST API |
| 5 | Оформить проектную документацию (диаграммы, SQL, CRUD-матрица, экспорт) |

## Целевая аудитория

- Студенты и аспиранты — бронирование на практикумы и проекты.
- Преподаватели и руководители групп (исследователи) — планирование занятий и НИР.
- Технический персонал — учёт ремонта и обслуживания.
- Администраторы лабораторий — пользователи и оборудование внутри организации.
- Системные администраторы платформы — несколько лабораторий, настройка доступа к БД.

## Технологический стек

- **Backend:** Node.js, Express  
- **БД:** MySQL / MariaDB  
- **Frontend:** Jade-шаблоны (прототип UI), планируется React-клиент  
- **Безопасность:** bcrypt, JWT, cookie
